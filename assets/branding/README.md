# Tink brand assets

`mark.png` (1024 px), `tink-mark.svg`, native launcher/adaptive/notification
assets, and web icons are an original vector redraw of the head and yellow
spark reference supplied for this project. The yellow is confined to this mark.
`TinkMarkPainter` is the matching in-app vector. The six introductory finance
compositions are original Flutter canvas artwork (`tink_illustration.dart`), not
stock art, third-party bank cards, or copied Stable Money screens.

Regenerate raster/native icons with `python3 tools/generate_branding.py`
(development dependencies: `pillow`, `aggdraw`). Poppins and Inter font licenses
are bundled alongside the fonts. Circular Std is not bundled or implied licensed.
